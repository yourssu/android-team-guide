# android-team-guide
유어슈 안드로이드 팀 가이드 문서 레포지토리 (in progress 🚧)

## 가이드의 종류

- **컨벤션 (Convention)**: 일관성을 위해 팀에서 사용하는 간단한 규칙
- **프로세스 (Process)**: 일하는 과정이나 특정 프로세스에 대한 설명

## 가이드 유의사항

> `가이드`는 `컨벤션`과 `프로세스`를 통틀어 부르는 용어입니다.

- 유어슈 안드로이드 팀원은 모든 가이드를 숙지해야 합니다.
- 모든 가이드는 업데이트 되기 전 모든 멤버가 확인(approve)하는 것을 권장합니다.
- 모든 가이드는 최소한의 규칙만 유지해야 합니다. 꼭 필요한 규칙인지 상시 검토가 필요합니다.
- 모든 가이드의 문체는 하십시오체(~습니다, ~합니다)를 권장합니다.
- 모든 컨벤션은 그것이 존재하는 이유나 배경에 대한 설명이 포함되어야 합니다. trivial한 경우에는 생략할 수 있습니다.
- 누구나 가이드의 생성/수정/삭제를 요청할 수 있으며, 오픈소스로서 모든 기여가 열려있습니다. [가이드 업데이트 프로세스](./Process/가이드_업데이트_프로세스.md)와 [CONTRIBUTING.md](./CONTRIBUTING.md)를 참고해주세요.
